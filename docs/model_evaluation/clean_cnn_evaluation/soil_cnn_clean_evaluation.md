## 1. Executive Summary: Leaked vs. Clean Evaluation

In Phase 6 Task P1, the baseline evaluation of `soil_cnn_v1.h5` reported **90.10% test accuracy** on the historical split `soil_cnn_splits.json`. However, the P1.1 dataset audit revealed that **33.7% of that test set consisted of near-duplicate frames** leaked from the training set (including 55.8% of `Alluvial` test samples).

Evaluating the exact same model weights on the clean, deduplicated test split (`soil_cnn_splits_v2.json`, $n = 71$) yields a true generalization accuracy of **81.69%**:

| :--- | :---: | :---: | :--- |
| **Test Accuracy** | `90.10%` (91/101) | **`81.69%`** (58/71) | $-8.41\%$ drop due to eliminating training frame memorization. |
| **Categorical Crossentropy Loss** | `0.3692` | **`0.4537`** | Higher loss reflecting genuine unseen image uncertainty. |
| **Macro Precision** | `0.9132` | **`0.8415`** | Solid precision across all 4 classes. |

| **Weighted F1-Score** | `0.8971` | **`0.8164`** | Consistent across balanced class supports. |

| **Clean Validation Accuracy** | `86.14%` (leaked val set) | **`90.00%`** (63/70, clean val set) | Strong internal feature representation confirmed. |

## 2. Pipeline Corrections Implemented in `evaluate_models.py`

The historical evaluation function in `backend/ml_training/evaluate_models.py` suffered from severe methodological flaws:
1. **Ignored Official Split Metadata:** It bypassed `soil_cnn_splits.json` entirely and called `ImageDataGenerator(validation_split=0.2)` on the raw `soil_images/` directory, randomly testing on a 20% slice that heavily overlapped with training data.
2. **Missing Granular Metrics:** It only printed `val_loss` and `val_acc` via `model.evaluate()`. It did not generate predictions, confusion matrices, or per-class reports.
3. **No Failure Handling:** It did not verify whether images existed on disk or if class mappings aligned.

### Corrections Implemented:
* **Exclusively Loads Clean Canonical Dataset:** Points strictly to `backend/ml_training/datasets/soil_images_clean/`.
* **Locks to Official Split Metadata:** Reads `backend/trained_models/soil_cnn_splits_v2.json` by default.
* **Deterministic MobileNetV2 Preprocessing:** Resizes with Pillow LANCZOS to $(224, 224)$ and normalizes pixel values to $[-1.0, 1.0]$ matching `mobilenet_v2.preprocess_input` with **zero data augmentation**.
* **Comprehensive Metrics Output:** Computes categorical loss, accuracy, macro/weighted precision/recall/F1, confusion matrix, and classification report.
* **Integrity Guardrails:** Asserts zero split overlap, verifies image existence on disk, validates class labels against `soil_cnn_classes.pkl`, and checks for empty test sets.

## 4. Per-Class Analysis & Generalization Insights

![Soil CNN Clean Evaluation Per-Class Performance](file:///D:/minor%201/Agrosmart/docs/model_evaluation/clean_cnn_evaluation/soil_cnn_clean_per_class.png)

### 4.1 Clay: Perfect Precision (100.0%) but Subdued Recall (66.7%)
* **Precision is 100.0%:** Whenever the model predicts `Clay`, it is **100% correct** ($10/10$). There are zero false positives from any other soil class.
* **Recall is 66.7% ($10/15$):** 4 `Clay` test samples were misclassified as `Alluvial`, and 1 as `Red`.
* **Root Cause:** Both alluvial and dry clay soils often share smooth, light-brown/tan textural features without prominent dark cracking. Because `Alluvial` had more training representation in the original model weights, the decision boundary was slightly biased toward `Alluvial` when color cues were ambiguous.

### 4.2 Black Soil: Major Recall Rebound ($66.7\% \rightarrow 88.9\%$)
* In the leaked evaluation, `Black` soil had the lowest recall (**66.67%**), which seemed like a severe flaw.
* In the clean canonical evaluation, `Black` soil achieved **88.89% recall** ($16/18$ correct) and an **F1-score of 0.8649**.
* **Reason:** In the clean dataset, dark organic soil features are strongly separated from clay and red soils. Only 2 samples were confused with dark alluvial silt.

### 4.3 Alluvial: Adjusted from Inflated 95.4% to Realistic 78.9%
* In the leaked evaluation, `Alluvial` reported **95.35% recall**, driven by 24 leaked duplicate video frames in the test set.
* In the clean canonical evaluation, `Alluvial` recall settled at a realistic **78.95%** ($15/19$ correct) with an F1-score of **0.7500**.
* This proves that the previous 95.4% metric was an artifact of test set memorization.

### 4.4 Red Soil: High Consistency (89.5% Recall, 0.8500 F1)
* Strong iron-oxide reddish hues provide distinctive chrominance features.
* 17 out of 19 samples were classified correctly. Only 2 darker red soil samples were predicted as `Black`.
