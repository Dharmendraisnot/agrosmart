Database Schema & Data ModelsThe system persists all operational data in an embedded SQLite database (`agrosmart.db`) using three core relational tables and one scaffolded authentication table:```┌─────────────────────────────────┐│         sensor_readings         │├─────────────────────────────────┤│ PK  id               : INTEGER  ││     timestamp        : DATETIME ││     source           : VARCHAR  ││     moisture         : FLOAT    ││     rainfall         : FLOAT    ││     ph               : FLOAT    ││     soil_temperature : FLOAT    ││     air_temperature  : FLOAT    ││     air_humidity     : FLOAT    ││     nitrogen         : FLOAT    ││     phosphorus       : FLOAT    ││     potassium        : FLOAT    │└────────────────┬────────────────┘                 │ 1                 │                 │ 0..*┌────────────────▼────────────────┐│          soil_analyses          │├─────────────────────────────────┤│ PK  id                   : INT  ││     timestamp            : DATE ││ FK  sensor_reading_id    : INT  │◄── Linked to sensor_readings.id│     soil_image_path      : TEXT ││     soil_type            : TEXT ││     soil_type_confidence : FLT  ││     soil_health_status   : TEXT ││     health_score         : FLT  ││     notes                : TEXT │└────────────────┬────────────────┘                 │ 1                 │                 │ 3┌────────────────▼────────────────┐│           predictions           │├─────────────────────────────────┤│ PK  id                 : INT    ││     timestamp          : DATE   ││ FK  analysis_id        : INT    │◄── Linked to soil_analyses.id│     prediction_type    : TEXT   │   ("crop" | "fertilizer" | "irrigation")│     result_json        : TEXT   │   (Structured JSON payload)│     top_recommendation : TEXT   │   (e.g., "wheat", "DAP", "Irrigate...")│     model_version      : TEXT   │   (e.g., "rf_v1.0", "prototype_v1.0")└─────────────────────────────────┘```Table Specifications:`sensor_readings` (`SensorReading`):Captures telemetry snapshots from either `source="simulator"` or `source="manual"`.Preserves `rainfall` (meteorological precipitation, mm) and `moisture` (soil moisture content, %) as separate physical metrics.Includes full macronutrient columns (`nitrogen`, `phosphorus`, `potassium` in mg/kg).`soil_analyses` (`SoilAnalysis`):Represents a consolidated diagnostic event linked to a specific `sensor_reading_id`.Stores the CNN classification outcome (`soil_type`, `soil_type_confidence`), image path, and composite health score ($0\text{--}100$).`predictions` (`Prediction`):Exactly three prediction rows are committed per analysis event: `crop`, `fertilizer`, and `irrigation`.Full model payloads are serialized in `result_json` with top recommendation extracted into a string column for rapid history queries.`users` (`User`):Scaffolded ORM table (`id`, `username`, `password_hash`, `role`). Auth is disabled in MVP to allow frictionless dashboard access.---4. Frontend UI Pages & FeaturesDashboard (`Dashboard.jsx`):Surfaces real-time parameter cards (Moisture, pH, N, P, K, Soil Temp, Air Temp, Humidity).Automated 10-second polling cycle with live badge indicators (`Software Active`).Recharts telemetry chart visualizing historical variations over time.Soil Analysis Workstation (`SoilAnalysis.jsx`):Step 1: Optional soil photo upload widget with MobileNetV2 CNN classification preview.Step 2: Manual 8-parameter entry form with preset shortcuts (e.g. Rice-friendly Loamy, Dry Sandy, Fertile Clay).Step 3: Conditional texture confirmation dropdown for Alluvial soils.Step 4: Consolidated results display featuring soil classification, composite health gauge, top-3 crop cards, fertilizer dosage, and irrigation action plan.Dedicated Advisories (`CropRecommendation.jsx`, `FertilizerAdvice.jsx`, `IrrigationAdvice.jsx`):Deep-dive diagnostic views isolating specific model outputs, explaining crop probability distributions, fertilizer nutrient ratios, and evapotranspiration calculations.Historical Archive (`History.jsx`):Paginated historical table with expandable rows.Shows past dates, CNN classifications, health status, and top recommendations with thumbnail previews.---6.
