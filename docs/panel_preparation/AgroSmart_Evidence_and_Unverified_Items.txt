Explicit System Status DemarcationTo prevent misrepresenting capabilities during panel evaluation, the system features are classified into four categories:Category A: Fully Implemented & Functionally VerifiedReact 18 single-page application and parameter input workstation.8-parameter manual input form with agricultural presets.Soil image upload widget with MIME-type sniffing and UUID collision protection.MobileNetV2 CNN soil order classification ($90.10%$ test accuracy).Random Forest top-3 probabilistic crop recommendation.Decision Tree prototype fertilizer recommendation with scientific crop mapping.Alluvial soil texture safeguard (withholding advice until texture is confirmed).Deterministic 4-component soil health scoring index ($0\text{--}100$).Effective moisture irrigation advice engine accounting for soil drainage and crop demand.SQLite persistence of readings, multi-model analyses, and individual prediction rows.Automated test suites (111 pytest tests, 4 end-to-end workflows, in-process smoke tests).Category B: Partially Implemented / PrototypeFertilizer Model Data Basis: The Decision Tree is trained on the Kaggle Fertilizer Prediction dataset ($99$ rows). It serves as a pipeline prototype and requires retraining on local field samples (`fertilizer_dt_final.pkl`).User Authentication: The `User` ORM model is scaffolded in SQLAlchemy, but authentication routes and JWT protection are currently disabled in MVP mode.Category C: SimulatedEnvironmental Sensor Telemetry: When manual inputs are not supplied, live sensor feeds are generated by `SimulatedSensor` using sinusoidal drift equations. Physical hardware is not connected.Category D: Planned (Phase 5 Roadmap)Physical Raspberry Pi 5 integration using SPI MCP3008 ADC.Physical capacitive soil moisture probe, analog pH probe, DS18B20 1-Wire temperature sensor, and RS485 UART NPK probe.Real-time soil image capture via Raspberry Pi Camera Module.Closed-loop relay control for automated irrigation solenoid valves.Field calibration and validation trials with local farming communities.---3.
